GVHMR on Google Colab

The original GVHMR Colab notebook, fixed with minimal changes · October 2026

GVHMR's own code is unchanged. The notebook stopped working only because Google Colab now runs Python 3.13, while GVHMR's requirements need Python 3.10. The fix installs GVHMR into a small Python 3.10 environment. Tested end to end on a free Colab T4 GPU.

How to run it

  1. Open the notebook in Colab (button above). Optional: File › Save a copy in Drive to keep your own copy.
  2. Runtime › Change runtime type › T4 GPU (already selected), then Runtime › Run all. Setup + the two demo videos take about 10 minutes.
  3. At the end, under Upload Your Own Video, click Choose Files and pick your video. The result appears under the cell. Use static_camera=True for a tripod / fixed camera, False for a moving camera.

What changed (only tools/demo/colab_demo.ipynb)

  • Install cell: installs GVHMR's original requirements.txt into a Python 3.10 environment (plus setuptools<81, and chumpy installed separately because its setup script breaks with new pip).
  • Run lines: demo.py runs with that Python 3.10.
  • display_video: reads the video size with OpenCV instead of importing GVHMR in Colab's own Python.
  • "Try it yourself" cell: commented out (it always errored, which stopped Run all).
  • New: a small Upload Your Own Video section (Choose Files button).

Tips

  • Colab Pro is not needed; the free T4 works. Each new Colab session starts empty, so use Run all again.
  • Big video? Drag it into the Files panel (folder icon on the left) and run demo_uploaded_video(static_camera=True, path='/content/your_video.mp4').
