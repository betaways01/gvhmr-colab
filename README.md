# GVHMR on Google Colab: original notebook, fixed with minimal changes

Google Colab now runs Python 3.13, but [GVHMR](https://github.com/zju3dv/GVHMR)'s requirements need Python 3.10, so the official
Colab notebook stopped working. The fix changes only the notebook (install cell → Python 3.10 environment, demo runs with it);
GVHMR's own code is unchanged. Tested end to end on a free Colab T4 (October 2026).
